무드녹색 펠트 · 나무 테두리 · 흰 카드. 마작 클래식·맞고와 같은 테이블 게임 결먹색 바탕에 금테, 양피지색 카드. 용·봉황·개·마작 4장이 주인공밝은 한지색, 평면 카드. 처음 하는 친구에게 가장 읽기 쉬움

공통 가정 — 표준 티추(56장: 4무늬 × 2~A + 마작·개·봉황·용). 4명이 2:2 팀, 같은 팀은 맞은편. 라운드마다 8장 → 그랜드 티추 선택 → 6장 더 받기 → 티추 선택 → 3장 패스(왼쪽·파트너·오른쪽에 1장씩) → 마작(1) 가진 사람이 선. 카드 점수는 5=5점 · 10=10점 · K=10점 · 용 +25 · 봉황 −25(한 라운드 총 100점). 같은 팀 1·2등이면 200점, 티추 성공 +100/실패 −100(그랜드는 ±200). 사람이 모자라면 AI가 빈자리를 채우고, 사람 2명일 땐 파트너/상대 중 선택.
결정이 필요한 것
  1. 룰 범위 — 표준 전체(그랜드 티추·소원·용 선물·폭탄 가로채기)를 처음부터 넣을지, 간소화 버전으로 시작할지. (제안: 표준 전체. 구현은 어렵지 않고 빼면 티추 맛이 사라짐)
  2. 폭탄 가로채기 — 폭탄은 내 차례가 아니어도 낼 수 있음. 실시간 게임이라 "누가 낸 뒤 N초 안에 폭탄 버튼이 있으면 눌러서 끼어들기" 같은 대기 창이 필요. 이 시안엔 아직 안 넣음 → 다음 시안에서 같이 잡자.
  3. 사람 2명일 때 자리 — 친구를 파트너로 / 상대로 / 방 설정에서 고르기(이 시안은 방 설정에서 선택 가정).
  4. 봉황 처리 — 스트레이트·풀하우스에서 봉황이 무엇이 될지 자동 추정 + 애매할 때만 선택 팝업 vs 항상 선택.
  5. 카드 아트 — 특수 4장(용·봉황·개·마작)을 한자 글리프로 둘지, 일러스트(GPT-Image/PixelLab)로 만들지.
  6. 도우미 수준 — '낼 수 있는 조합' 칩(C)을 옵션으로 둘지, 기본으로 둘지. 한 팀 AI 파트너의 티추 콜 정책/난이도.
